# Airbnb Market Analysis

## Project Overview
This project analyzes Airbnb listings to explore pricing patterns, neighbourhood distribution, room types, customer reviews, and listing availability.

## Objectives
- Analyze listing price distribution.
- Compare average prices across neighbourhood groups.
- Explore the distribution of room types.
- Compare reviews and availability across room types.
- Identify data-quality issues that may affect the analysis.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
**Airbnb Open Data**  
Source: [Kaggle — Airbnb Open Data](https://www.kaggle.com/datasets/arianazmoudeh/airbnb-open-data)

## Key Analysis
- Listing price distribution
- Average price by neighbourhood group
- Listing distribution by room type
- Average reviews by room type
- Average availability by room type

## Key Findings
- Listing prices vary across neighbourhood groups.
- Entire homes/apartments and private rooms are the most common room types.
- Hotel rooms show a higher average review count, but the number of hotel-room listings is relatively small.
- Availability represents the number of days a listing is marked available, not the number of days it was booked.
- Missing values and data-quality issues should be considered when interpreting results.

## Limitations
- Some listings have missing price values.
- The dataset contains data-quality issues.
- Differences in sample sizes may affect comparisons.
- The analysis identifies patterns and associations, not causation.

## Conclusion
This project uses Python and its data-analysis libraries to explore Airbnb listing prices, neighbourhoods, room types, reviews, and availability.
